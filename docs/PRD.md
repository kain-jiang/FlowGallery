## 1. 产品概述

### 1.1 背景与问题

图包、画集、素材收藏爱好者通常将图片按主题整理在多个文件夹中（如 `Landscapes/`、`Portraits/`、`Architecture/`）。现有手机图库存在以下痛点：

1. **无法聚合多文件夹**：系统图库按相册聚合，但自定义文件夹层级深、分散，浏览不便。
2. **缺少瀑布流视图**：系统图库为等宽网格，无法突出不同比例图片的视觉效果；Pinterest 式瀑布流更利于快速扫图。
3. **图包预览效率低**：打开图包需逐级进入目录，无法"一次添加、持续浏览"。

macOS 端 FlowVision 通过"选择多个文件夹 → 瀑布流浏览"解决了桌面端问题，但移动端缺乏同类产品。

### 1.2 产品定位

**FlowGallery 是一款面向图包/画集收藏者的安卓瀑布流图库浏览器**，核心价值：

> 一次选择多个文件夹，以 Pinterest 式瀑布流聚合浏览全部图片，支持文件夹维度筛选、全屏沉浸查看。

### 1.3 设计稿范围

本文档以 `flowgallery-android.html` 交互原型为唯一视觉与交互基准。原型包含以下完整界面：

- 首页（Home）：瀑布流 + 文件夹标签栏 + 统计栏 + FAB
- 文件夹选择模态框（Folder Modal）
- 全屏查看器（Viewer）
- 搜索页（Search）
- 设置页（Settings）

## 2. 目标用户与使用场景

### 2.1 目标用户

| 用户群 | 特征 | 核心诉求 |
|---|---|---|
| 二次元画集收藏者 | 拥有大量"图包"（按角色/画师/主题分文件夹） | 快速扫图、多文件夹聚合 |
| 设计师/素材收集者 | 图片素材按项目分类存放 | 效率浏览、质量识别（HD/SD） |
| 摄影爱好者 | 按拍摄场景分文件夹 | 瀑布流浏览、收藏精选 |

### 2.2 典型使用场景

1. **图包聚合浏览**：用户添加 3 个图包文件夹，首页默认"All"聚合显示全部图片（含数量统计），按文件夹标签切换查看单个图包。
2. **快速扫图**：上下滑动瀑布流快速浏览，卡片左下角 HD/SD 徽章帮助识别质量，点击心形即时收藏。
3. **沉浸看图**：点击图片进入全屏查看器，双指缩放 1x–4x、滑动切换、底部缩略图条跳转。
4. **图库维护**：在设置页开关文件夹（临时隐藏）、添加新文件夹。

| 维度 | FlowGallery | 系统相册 | Pinterest | macOS FlowVision |

## 5. 功能需求

### FR-1 瀑布流网格（P0）

**描述**：Pinterest 风格瀑布流，图片按真实宽高比自适应高度；列数在设置页按方向独立配置，支持强制单列。

**需求细节**：
- 瀑布流布局（true masonry），图片按真实宽高比分配（决策 #1 自适应已由设置列数替代）
- **列数配置（设置页选择框）**：竖屏 2/3/4 列 + 横屏 2–6 列**独立设置**（决策 #1 更新），选择持久化
- **强制单列开关**：标题栏右侧 ViewAgenda 图标 — 激活时紫色，强制 1 列（优先于设置）；**首页与收藏页各自独立**的单列开关
- 图片卡片圆角 12px，保留原始宽高比（非裁剪）
- 卡片加载时显示同比例占位（防跳动）
- 卡片下方渐变压暗层（底部 → 透明）
- 滚动使用懒加载，仅渲染可视区域
- **媒体类型识别**（决策 #5）：扫描时识别文件类型（静态图 / 动画 GIF / 动画 WebP / 视频），瀑布流卡片对动画与视频显示首帧预览，并在卡片右上角叠加类型角标（GIF / WEBP / 视频图标）；静态图无角标
- 动图与视频在卡片上不自动播放（节省资源），点击进入查看器后播放

**交互**：
- 点击卡片 → 打开全屏查看器
- 卡片按压反馈：scale(0.98)
- **下拉刷新**（FR-9）：首页下拉重新扫描已选文件夹

**验收标准**：
- 混合比例图片（竖图/横图/方图）下两列高度差 ≤ 一张卡片高度
- 快速滚动 500 张图无卡顿、无白屏闪烁
- 列数 2↔3 切换后重启应用，选择保持
- 动画/视频卡片显示首帧与类型角标，滚动列表时不自动播放
- 瀑布流中混合静态图/动图/视频，滚动流畅无卡顿

### FR-2 文件夹管理（P0）

**描述**：通过系统文件夹选择器（SAF）添加多个文件夹，支持**类型选择**、开关、移出与聚合。

**需求细节**：
- **添加**：FAB 或设置页 → 系统 SAF 目录选择器 → 授权后弹出**文件夹类型选择框**（见下）→ 确认加入
- **文件夹类型**（添加时手动选择，推荐预选）：
  - **普通文件夹**：内容直接展示，子文件夹不单独索引（递归收集但不生成子文件夹条目、不参与跨目录浏览链）
  - **图包目录**：一级子文件夹单独索引为可浏览条目（子文件夹标签 + 跨目录连续浏览）
  - 推荐逻辑：检测文件夹树含子目录 → 推荐"图包目录"，否则"普通文件夹"；用户可改
  - 类型持久化；设置页类型徽章可点击**随时修改类型**（修改后重新扫描）
- **去重**：同一目录重复添加自动忽略；被已有条目覆盖的树（SAF document id 前缀匹配）拒绝添加
- **持久化**：目录授权与列表跨重启保留
- **开关**：设置页可临时停用某文件夹（不删除授权）
- **移出**：删除列表条目并释放 SAF 持久化授权（`releasePersistableUriPermission`），瀑布流与统计同步消失；移出前弹出确认对话框（提示图片数量）

**交互**：
- 文件夹选择器（下拉，替代标签栏）：单行卡片（圆角 14px），图标 + 当前路径文本（`文件夹 / 子文件夹`）+ 计数 + 下拉箭头；下拉菜单为深色圆角 20px 卡片，菜单项 = 图标 + 名称 + 数量，子文件夹缩进 + 图标淡化区分，无分隔线
- 文件夹模态框：底部弹出，带拖动把手，多选勾选 + "Add New Folder" 按钮
- 移出入口：设置页文件夹条目右侧 × 按钮 + 确认对话框

**验收标准**：
- 添加 3 个文件夹后重启应用，文件夹列表、类型与授权保持
- 添加时弹出类型选择框，推荐类型正确预选，确认后按类型扫描
- 修改类型后（设置页徽章点击）重新扫描，子文件夹索引行为相应变化
- 开关关闭某文件夹后，首页统计与瀑布流即时更新
- 重复/被覆盖的目录添加被拒绝
- 移出后：列表条目消失、系统授权释放、瀑布流与统计即时更新；重启后不再出现

### FR-2.1 子文件夹递归浏览（P0）

**描述**：图包目录若包含子文件夹，按一级子文件夹维度递归浏览其下所有图片（含孙子层级的图片，即"图包套图包"场景）。

**需求细节**：
- **递归范围**：以用户添加的图包目录为根，向下递归所有层级子文件夹，收集全部图片（含子文件夹、孙文件夹……），聚合到该文件夹视图
- **子文件夹身份稳定**：子文件夹 id 由文档 URI 哈希派生（非扫描计数器），跨扫描不漂移；item↔子文件夹用**文档 URI**（subFolderUri）匹配
- **懒加载浏览**：查看器只加载当前子文件夹内容，不预加载兄弟子文件夹
- **跨目录连续浏览**：在当前子文件夹最后一张继续 → 下一子文件夹第一张；第一张继续向前 → 上一子文件夹最后一张；**首个子文件夹开头 / 末个子文件夹结尾为真端点**（不循环）
- **返回同步**：跨目录后返回首页，首页自动切换到正在浏览的子目录视图
- **浏览顺序一致**：查看器顺序与首页当前排序模式一致
- **普通文件夹不索引**：普通文件夹的子文件夹递归收集但不建条目
- **性能**：递归扫描在 IO 线程异步执行，零内容 IO（尺寸后台解析）

**交互**：
- 下拉选择器选择子文件夹（缩进显示），统计栏显示该子文件夹递归总数
- 查看器底部缩略图条只显示当前子文件夹内容，自动滚动居中当前项

**验收标准**：
- 添加含 2 层嵌套子文件夹的图包目录：父视图计数 = 全部层级图片总数；子文件夹计数正确
- 子文件夹 id 跨重启/重扫稳定，选中状态不漂移
- 跨目录浏览：末张→下一子文件夹首张、首张→上一子文件夹末张；首/末子文件夹边界不循环
- 返回首页后定位到正在浏览的子文件夹
- 普通文件夹无子文件夹条目
- 深层嵌套（≥3 层）扫描不崩溃、滚动流畅

### FR-3 全屏查看器（P0）

**描述**：全屏沉浸式媒体查看器，图片/视频交互完全一致，支持滑动切换、跨子目录浏览、视频全屏纯播放。

**需求细节**：
- **交互一致性**：图片与视频统一 —— 点击画面切换工具栏显隐；左右滑动切换媒体（HorizontalPager，资源左右拼接、滑动同步移动、垂直拖动不误触；图片 1x 时、视频均可滑动；图片放大时滑动=平移）
- **缩放**：图片双指捏合 1x–4x 或**双击缩放**（双击放大到铺满全屏的最小比例 coverScale，再双击还原 1x）；超过 1x 时可平移（视频不缩放）；捏合放大下限=coverScale（放大后无黑边）
- **导航**：左右箭头按钮；页内为单箭头 ‹ ›，**子文件夹边界显示双箭头 « » 跨目录**（仅在确实存在相邻子文件夹时显示，见 FR-2.1）；普通视图首/末张箭头隐藏
- **缩略图条**：底部横排**当前子文件夹**缩略图，当前项高亮，**自动滚动居中**当前项，点击跳转
- **画布全屏**：查看器媒体铺满整屏（无 safeDrawing 内边距，消除顶部黑缝）；顶部操作栏/底部缩略图条各自独立避让状态栏/挖孔/手势条
- **信息**：底部显示文件名 + 尺寸（宽 × 高，加载后解析）
- **操作栏**：顶部返回、收藏、分享、更多（分享 = 系统分享面板；更多菜单提供"保存到相册"）；**按钮风格**：无背景图标 + 强调色光晕（禁用黑色/纯色块）
- **沉浸**：进入查看器隐藏系统状态栏/导航栏，退出恢复
- **收藏页来源索引**：从收藏 Tab 打开查看器时，浏览序列**仅限收藏项**（favoritesOnly），滑动/箭头不会切到未收藏媒体
- **媒体播放**：
  - 静态图：缩放/平移（1x–4x）
  - 动画 GIF/WebP：自动循环播放（Coil 解码动图），可缩放平移
  - 视频：Media3 ExoPlayer + **自定义控制条**（播放/暂停 + 进度条 + 时间 + **音量静音开关** + 全屏按钮，无背景遮罩）；**进度条拖动实时跟手**（拖动中本地显示、松手 seek、不闪回）；**只有进度条能改进度**（画面滑动=切换媒体）
  - **视频全屏模式**：控制条全屏按钮 → Activity 旋转横屏，进入**纯播放视图**（无箭头/缩略图条/浏览 UI，滑动切换禁用）；点击画面可隐藏/显示控制条；返回键退出全屏；**切换全屏时播放进度保持**（同一播放器实例）
  - **中央播放按钮**（暂停时）：72dp 可点区域 + 48dp 白色三角 + **56dp 紧凑强调色圆环**（2dp 紫色细环 + 柔和紫色光晕，无背景圆盘，直接叠加画面）
- **重复文件**：去重后保留项在底部显示"该文件有 N 个副本"提示条，点击弹出深色卡片列表（每个副本：文件名 / 文件夹路径 / MD5 等宽显示，当前文件紫色高亮）

**验收标准**：
- 图片/视频点击画面、滑动切换行为一致
- 缩放平滑无跳变，1x→4x 无极变速；放大时滑动=平移不翻页
- 缩略图条自动滚动居中当前项，跨目录后只显示当前子文件夹
- 视频播放/暂停/拖动进度正常；进度条拖动实时跟手、松手无闪烁、不误触切换
- 视频全屏：横屏纯播放、点击隐藏控制条、返回退出、进度保持
- 混合媒体（静态图+动图+视频）连续滑动切换不崩溃、不卡顿
- 重复文件弹窗列出所有副本路径与 MD5

### FR-4 文件夹标签与统计（P1）

**描述**：首页提供文件夹维度筛选与图库概览统计；标题+选择器作为瀑布流 header 随内容滚动隐藏。

**需求细节**：
- **文件夹选择器（下拉）**：单行卡片（圆角 14px），图标 + 当前路径（`文件夹 / 子文件夹`）+ 计数 + 下拉箭头；菜单为深色圆角 20px 卡片（无分隔线），子文件夹缩进 + 图标淡化；**弹窗宽度与选择框一致并对齐**（BoxWithConstraints 精确计算）
- 标签顺序：`All [去重后总数]` → 各文件夹（含子文件夹缩进项）
- **滚动隐藏**：标题栏 + 选择器作为瀑布流 full-span header item，向下滚动随内容一起滚出（速度 1:1）；完全滚出后显示**置顶胶囊**（当前路径 + ↑ 图标，点击滚回顶部；`safeDrawing` inset 避开挖孔屏）
- **浮动统计胶囊（右下角，替代 FAB）**：`图片数` / `文件夹数` / `HD 数`，仅图标+数字（无文字标签）
  - 文件夹项逻辑：浏览**图包**文件夹时显示**子文件夹数量**，点击弹出子文件夹选择（选中项 ✓ 标记）；**普通文件夹 / All 视图不显示**文件夹项
  - 胶囊整体消费点击（不穿透到瀑布流误开查看器）
- 图片数随当前选择联动（All=去重总数，文件夹/子文件夹=全量计数）
- **空状态保留标题栏+选择器**（防止关闭文件夹后无法切换视图）；关闭当前浏览文件夹自动回退 All

### FR-5 质量标识 HD/SD（P1）

**描述**：缩略图左下角显示分辨率质量徽章。

**规则**：
- 宽 ≥1920 或 高 ≥1080 → HD（绿色徽章）
- 其余 → SD（橙色徽章）

- 收藏状态跨会话保留（本地持久化）
- **收藏页（独立 Tab）**：展示全部已收藏图片（跨文件夹聚合），复用瀑布流与查看器；取消收藏后即时消失；空状态引导（"点击任意图片上的心形即可加入收藏"）

- **首页不再提供收藏过滤**（下拉选择器无收藏项）

**验收标准**：
- 收藏/取消双向同步（卡片 + 查看器）
- 收藏页独立 Tab 展示全部收藏，取消后即时消失

### FR-10 视频与动图支持（P1）

**描述**：图库统一管理静态图、动画 GIF/WebP 与视频，扫描、浏览、查看全链路支持。

**需求细节**：
- **扫描范围**：文件扫描同时匹配 `image/*` 与 `video/*` MIME；扩展名识别：静态图（jpg/jpeg/png/webp/bmp/heic/avif）+ 动画（gif、动画 webp）+ 视频（mp4/mkv/webm/mov/avi/flv/ts/m4v/wmv/rmvb/mpg/mpeg/rm）
- **类型判定**：GIF 与 WebP 通过解码帧数判定是否为动画；视频按扩展名/MIME 判定
- **瀑布流**：动画/视频卡片显示预览帧 + 类型角标（GIF/WEBP/▶）；列表滚动时不自动播放；视频不显示 HD/SD 质量徽章
- **智能视频缩略图**：默认取首帧；**首帧纯黑（>90% 像素低于亮度阈值）时按 1s/2s/4s/8s/16s 递增取样，取第一个非黑帧**作为缩略图（卡片 / 查看器封面 / 缩略图条通用）；首帧不黑时零额外开销
- **查看器**：动图自动循环播放；视频使用自定义播放器（见 FR-3）
- **缩略图条**：视频缩略图带播放角标，动图缩略图带 GIF 角标

**验收标准**：
- 含静态图/GIF/WebP 动画/MP4 的文件夹扫描后，四类文件均出现在瀑布流，角标正确
- 动图在查看器自动循环播放；视频播放器播放/暂停/拖动可用
- **首帧纯黑的视频显示后续非黑帧作为缩略图**
- 视频文件损坏或无法解码时跳过不崩溃

### FR-11 排序能力（P1）

**描述**：首页图片浏览支持按时间 / 文件大小 / 图片质量排序，预览卡片上展示排序依据的值。

**需求细节**：
- **排序模式**（标题栏排序按钮，下拉菜单选择，选择持久化）：
  - 默认（扫描顺序）
  - 最新优先（按修改时间倒序）
  - 最旧优先（按修改时间正序）
  - 文件最大（按文件大小倒序）
  - 文件最小（按文件大小正序）
  - 画质优先（HD > SD > 视频）
- **排序依据值展示**：卡片右下角以深色半透明圆角小标签显示当前排序依据的值：
  - 时间模式：格式化日期（当年显示 `MM-dd`，跨年显示 `yyyy-MM-dd`）
  - 大小模式：人类可读大小（`B / KB / MB / GB`，如 `2.3 MB`）
  - 画质模式：复用左下角 HD/SD 徽章（不额外显示）
- **扫描元数据**：扫描时读取 SAF `COLUMN_SIZE` 与 `COLUMN_LAST_MODIFIED`（零 IO，随目录查询一并获取）
- **范围**：排序对"全部 / 收藏 / 文件夹 / 子文件夹"所有视图生效；查看器索引顺序跟随排序结果

**交互**：
- 标题栏排序按钮图标（Sort），激活非默认模式时图标高亮为紫色
- 下拉菜单样式与文件夹选择器一致（深色卡片、无分隔线、选中项紫色勾选）

**验收标准**：
- 六种排序模式均正确排序，切换即时生效
- 时间/大小值在卡片上正确显示，格式符合规范
- 排序选择重启后保持
- 排序与筛选（文件夹/子文件夹/收藏）组合工作正常
- **查看器浏览顺序与首页排序一致**

### FR-12 内容去重与重复文件查看（P1）

**描述**：跨文件夹内容级去重（文件大小 + MD5），且去重后的媒体可查看所有副本路径与哈希。

**需求细节**：
- **去重范围**：仅"全部（All）"视图去重；**文件夹 / 子文件夹 / 收藏视图保留全量**（同一媒体在不同文件夹各显示一份）
- **去重算法**：按文件大小分组 → 同大小文件计算 **MD5** → 大小 + MD5 均相同判为重复，保留第一份；唯一大小的文件零读取开销
- **来源去重**：添加文件夹时拒绝已被现有条目覆盖的树（SAF document id 前缀匹配，含相同/子/父路径），从源头防止重复
- **重复文件查看**：去重后的保留项在查看器底部显示"该文件有 N 个副本"提示条 → 点击弹出**深色卡片弹窗**（拖动把手 + 24px 圆角），列出每个副本：文件名 / 文件夹路径（根 / 子文件夹）/ **MD5（等宽字体）**，当前文件紫色高亮
- **全量保留**：`images` 保留完整扫描集，仅维护"All 视图去重 id 集合"；All 计数 = 去重后数量

**验收标准**：
- 相同内容复制到两个不同文件夹 → All 视图只显示一份，各自文件夹视图均完整
- 重复文件弹窗列出所有副本的文件名、路径、MD5
- 被覆盖的目录添加被拒绝
- 去重不误删：不同内容同大小文件均保留

## 7. 视觉规范（依据设计稿浏览器实测分析）

> 本节依据 `flowgallery-android.html` 在 Chromium 中的实际渲染逐界面分析提取。
> **本项目所有后续变更一律以本设计稿的样式风格为准。**

### 7.0 设计语言与风格原则（关键）

从设计稿提炼的核心 UI/UX 风格，任何新功能/组件必须遵循：

1. **深色沉浸基调**：全局深色背景（`#0A0A0C`），内容层用深灰卡片（`#141418` 系）浮起，层级靠"明度差"而非"边框线"区分 —— **优先使用留白和色阶分层，避免使用分隔线/描边**
2. **紫色单一强调**：`#7C5CFF` 是唯一强调色，只用于：激活/选中态、主操作（FAB、Add 按钮）、图标点缀。其他元素保持灰阶
3. **圆角体系**（统一语言）：
   - 卡片/条目：12px
   - 图标容器：8px
   - 标签胶囊：20px
   - 模态框/弹窗：顶部 24px（底部弹出式）
   - 徽章小标：4px
4. **卡片式条目**：列表条目 = 圆角卡片 + 左侧 40–48px 圆角图标容器（内嵌图标）+ 名称/描述两行文本 + 右侧操作元素；间距 8–12px
5. **弹窗/模态框统一为底部弹出卡片**：拖动把手（40×4px 圆角 2px）+ 大圆角 + 背景遮罩淡入 + 内容上滑 0.3s；**不使用系统默认 AlertDialog 白底样式**
6. **图标风格**：Material 线性图标（24px 基准），灰阶为主、紫色点缀；**不使用 emoji 或 Unicode 字符（如 ↳、›）充当图标**，层级用缩进/图标透明度表达
7. **文字层级**：主文字 `#F0F0F5` 15px SemiBold（条目名）→ 次级 `#A0A0B0` 12px（描述/路径）→ 弱化 `#606070` 9–11px（标签/计数）；等宽字体用于技术信息（尺寸、MD5）
8. **留白偏好**：页面水平内边距 16px，卡片内边距 12–16px，组件间距 8–12px；**宁可留白不要线条**
9. **动效克制**：0.2–0.3s 淡入/上滑/颜色渐变，按压 scale(0.98)，无夸张动画
10. **交互一致性**：同一类行为（点击画面、弹窗、选择器）在所有页面保持一致，不做页面特例

## 9. 数据模型（草案）

FolderType (enum)

├── isSelected: Boolean   # 是否启用
└── subFolders: List<SubFolder>   # 一级子文件夹（仅 PACK）
    └── SubFolder
        ├── id: Long              # 由文档 URI 哈希派生（跨扫描稳定）
        ├── name: String
        ├── uri: String           # 子文件夹文档 URI
        └── imageCount: Int

ImageItem
├── id: Long
├── folderId: Long        # 所属根文件夹
├── folderName: String
├── subFolderId: Long?    # 所属一级子文件夹（null=根目录直接图片）
├── subFolderUri: String? # 子文件夹文档 URI（稳定匹配键）
├── subFolderName: String?
├── name: String
├── uri: String           # 文档 URI

├── height: Int
├── sizeBytes: Long       # SAF COLUMN_SIZE（排序/去重用）
├── modifiedTime: Long    # SAF COLUMN_LAST_MODIFIED（排序用）

## 12. 开放问题决策记录

> 以下问题已在产品评审中确认，决策结果已同步到对应功能需求章节。

| # | 问题 | 决策 | 落点 |
|---|---|---|---|
| 1 | 是否需要多列自适应（横屏 3 列 / 平板 4 列）？ | **改为设置页按方向独立配置列数**：竖屏 2/3/4 列 + 横屏 2–6 列选择框（取代屏宽断点自适应）；另提供强制单列开关（首页/收藏各自独立） | FR-1 / FR-8 |
| 2 | 收藏是否需独立"收藏夹"视图？ | **需要，为独立 Tab（替换原搜索 Tab）**：底部导航 = 首页 / 收藏 / 设置；收藏页聚合全部已收藏图片（跨文件夹），复用瀑布流与查看器；首页下拉选择器不再提供收藏项；搜索改为首页搜索图标进入的覆盖层 | FR-6 / FR-7 |
| 3 | "网格切换"按钮（标题栏右侧）具体行为？ | **改为强制单列开关**：ViewAgenda 图标，激活时紫色强制 1 列（优先于设置列数）；收藏页有独立单列开关 | FR-1 / FR-8 |
| 4 | 分享按钮落地方式？ | **系统分享面板（ACTION_SEND + FileProvider）**，分享原图；"更多"菜单内提供"保存到相册"（写入系统媒体库） | FR-3 |
| 5 | 是否需要视频/动图（GIF/WebP 动画）支持？ | **v1.0 完整支持**：静态图 + GIF/WebP 动画 + 视频统一纳入图库；瀑布流中动画/视频显示首帧并带类型角标，进入查看器后动图播放、视频走播放器；扫描范围扩展至 image/* 与 video/* | FR-1 / FR-3 / FR-10 |
| 6 | 是否支持 Material You 动态取色？ | **支持（设置页开关）**：Android 12+ 用 `dynamicDark/LightColorScheme` 跟随壁纸配色，可随时切换回默认紫色主题 | FR-8 |
| 7 | 横屏/大屏导航布局？ | **横屏改用左侧 NavigationRail 常驻**（不参与首页滚动隐藏），内容区应用 displayCutout inset 避开挖孔屏；竖屏保持底部导航（可滚动隐藏） | FR-1 / 信息架构 |

**决策原则**：
- 所有决策以"低成本、不改变核心交互、可后续扩展"为准
- 与设计稿视觉规范冲突时以设计稿为准（如双列默认布局）
- 标注 v1.1 的能力仅在 PRD 中记录，不进入 M1–M3 范围
