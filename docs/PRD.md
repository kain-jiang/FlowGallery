## 1. 产品概述

### 1.1 背景与问题

图包、画集、素材收藏爱好者通常将图片按主题整理在多个文件夹中（如 `Landscapes/`、`Portraits/`、`Architecture/`）。现有手机图库存在以下痛点：

1. **无法聚合多文件夹**：系统图库按相册聚合，但自定义文件夹层级深、分散，浏览不便。
2. **缺少瀑布流视图**：系统图库为等宽网格，无法突出不同比例图片的视觉效果；Pinterest 式瀑布流更利于快速扫图。
3. **图包预览效率低**：打开图包需逐级进入目录，无法"一次添加、持续浏览"。

macOS 端 FlowVision 通过"选择多个文件夹 → 瀑布流浏览"解决了桌面端问题，但移动端缺乏同类产品。

### 1.2 产品定位

**FlowGallery 是一款面向图包/画集收藏者的安卓瀑布流图库浏览器**，核心价值：

> 一次选择多个文件夹，以 Pinterest 式瀑布流聚合浏览全部图片，支持文件夹维度筛选、全屏沉浸查看。

### 1.3 设计稿范围

本文档以 `flowgallery-android.html` 交互原型为唯一视觉与交互基准。原型包含以下完整界面：

- 首页（Home）：瀑布流 + 文件夹标签栏 + 统计栏 + FAB
- 文件夹选择模态框（Folder Modal）
- 全屏查看器（Viewer）
- 搜索页（Search）
- 设置页（Settings）

## 2. 目标用户与使用场景

### 2.1 目标用户

| 用户群 | 特征 | 核心诉求 |
|---|---|---|
| 二次元画集收藏者 | 拥有大量"图包"（按角色/画师/主题分文件夹） | 快速扫图、多文件夹聚合 |
| 设计师/素材收集者 | 图片素材按项目分类存放 | 效率浏览、质量识别（HD/SD） |
| 摄影爱好者 | 按拍摄场景分文件夹 | 瀑布流浏览、收藏精选 |

### 2.2 典型使用场景

1. **图包聚合浏览**：用户添加 3 个图包文件夹，首页默认"All"聚合显示全部图片（含数量统计），按文件夹标签切换查看单个图包。
2. **快速扫图**：上下滑动瀑布流快速浏览，卡片左下角 HD/SD 徽章帮助识别质量，点击心形即时收藏。
3. **沉浸看图**：点击图片进入全屏查看器，双指缩放 1x–4x、滑动切换、底部缩略图条跳转。
4. **图库维护**：在设置页开关文件夹（临时隐藏）、添加新文件夹。

## 3. 竞品分析

| 维度 | FlowGallery | 系统相册 | Pinterest | macOS FlowVision |
|---|---|---|---|---|
| 多文件夹聚合 | ✅ 多选文件夹合并浏览 | ❌ 按相册隔离 | ❌ 按话题流 | ✅ |
| 瀑布流布局 | ✅ 双列最短列分配 | ❌ 等宽网格 | ✅ | ✅ |
| 文件夹级筛选 | ✅ 标签栏切换 | 部分 | ❌ | ✅ |
| 全屏沉浸查看 | ✅ 缩放+滑动+缩略图条 | ✅ | 部分 | ✅ |
| HD/SD 质量标识 | ✅ 徽章 | ❌ | ❌ | ❌ |
| 本地图包管理 | ✅ SAF 免权限 | 部分 | ❌ | ✅ |

**差异化结论**：FlowGallery = 系统相册的本地图库能力 + Pinterest 的瀑布流体验 + FlowVision 的多文件夹管理，并增加质量标识、收藏等移动端特性。

## 5. 功能需求

### FR-1 瀑布流网格（P0）

**描述**：Pinterest 风格瀑布流，图片按真实宽高比自适应高度；默认双列，支持密度切换。

**需求细节**：
- 双列布局（默认），图片按"最短列优先"算法分配（true masonry）
- **列数切换**：标题栏右侧网格按钮在 2↔3 列间切换（决策 #3），选择持久化；切换时瀑布流平滑重排，浏览位置尽量保持
- **多列自适应预留**（M3）：横屏/大屏（屏宽 ≥600dp）自动 3–4 列，依据屏宽断点切换，卡片逻辑与双列完全复用（决策 #1）
- 图片卡片圆角 12px，保留原始宽高比（非裁剪）
- 卡片加载时显示同比例占位（防跳动）
- 卡片下方渐变压暗层（底部 → 透明）
- 滚动使用懒加载，仅渲染可视区域
- **媒体类型识别**（决策 #5）：扫描时识别文件类型（静态图 / 动画 GIF / 动画 WebP / 视频），瀑布流卡片对动画与视频显示首帧预览，并在卡片右上角叠加类型角标（GIF / WEBP / 视频图标）；静态图无角标
- 动图与视频在卡片上不自动播放（节省资源），点击进入查看器后播放

**交互**：
- 点击卡片 → 打开全屏查看器
- 卡片按压反馈：scale(0.98)

**验收标准**：
- 混合比例图片（竖图/横图/方图）下两列高度差 ≤ 一张卡片高度
- 快速滚动 500 张图无卡顿、无白屏闪烁
- 列数 2↔3 切换后重启应用，选择保持
- 动画/视频卡片显示首帧与类型角标，滚动列表时不自动播放
- 瀑布流中混合静态图/动图/视频，滚动流畅无卡顿

### FR-2 文件夹管理（P0）

**描述**：通过系统文件夹选择器（SAF）添加多个图包文件夹，支持开关、移出与聚合。

**需求细节**：
- **添加**：FAB 或设置页 → 系统 SAF 目录选择器 → 授权后加入图库
- **去重**：同一目录重复添加自动忽略
- **持久化**：目录授权与列表跨重启保留
- **开关**：设置页/模态框中可临时停用某文件夹（不删除授权）
- **移出**：将文件夹从图库中移除——删除列表条目并释放 SAF 持久化授权（`releasePersistableUriPermission`），其图片从瀑布流与统计中同步消失；移出前弹出确认对话框（提示图片数量），防止误操作

**交互**：
- 文件夹标签栏：`All [总数]` + 各文件夹 `[名称] [数量]`，激活态紫色高亮
- 点击标签 → 过滤瀑布流为该文件夹内容
- 文件夹模态框：底部弹出（Bottom Sheet），带拖动把手，多选勾选 + "Add New Folder" 按钮
- 移出入口：设置页文件夹条目左滑露出"移出"操作，或长按条目弹出菜单（移出/取消）；模态框中提供"移除"入口

**验收标准**：
- 添加 3 个文件夹后重启应用，文件夹列表与授权保持
- 开关关闭某文件夹后，首页统计与瀑布流即时更新
- 重复添加同一文件夹不产生重复条目
- 移出某文件夹后：列表条目消失、系统授权释放、瀑布流与统计即时更新；重启后不再出现
- 移出时弹出确认对话框，取消不产生任何变更

### FR-2.1 子文件夹递归浏览（P0）

**描述**：文件夹若包含子文件夹，按一级子文件夹维度递归浏览其下所有图片（含孙子层级的图片，即"图包套图包"场景）。

**需求细节**：
- **递归范围**：以用户添加的文件夹为根，向下递归所有层级子文件夹，收集全部图片（含子文件夹、孙文件夹……中的图片），聚合到该文件夹的瀑布流中
- **标签展示**：文件夹标签栏中，该文件夹的总计数 = 根目录 + 所有层级子目录的图片数之和
- **子文件夹独立标签**：若用户添加的文件夹包含一级子文件夹，标签栏在父文件夹之后以 `父文件夹/子文件夹` 形式展示每个一级子文件夹（含各自计数），点击可单独浏览该子文件夹递归范围内的图片；展开/折叠由标签栏横滑承载
- **面包屑感知**：进入子文件夹视图时，顶部可显示层级路径（如 `Landscapes > Sunset Pack`），点击父级路径返回
- **重复归属**：同一图片只归属其所在的实际文件夹标签；"All" 聚合视图按图片去重，不重复计数
- **性能**：递归扫描在 IO 线程异步执行；单文件夹超过 N 张（建议 5000）时按目录分批加载，滚动到接近底部时继续加载

**交互**：
- 首页标签栏出现子文件夹标签后，点击即切换到该子文件夹的瀑布流
- 当前处于子文件夹时，统计栏的图片数显示该子文件夹递归总数

**验收标准**：
- 添加含 2 层嵌套子文件夹的根目录后：父标签计数 = 全部层级图片总数；子文件夹标签计数 = 该子文件夹递归总数
- 点击任一子文件夹标签，瀑布流仅显示该子文件夹递归范围内的图片
- "All" 视图图片无重复（同一图片不出现两次）
- 深层嵌套（≥3 层）扫描不崩溃、不卡死主线程，滚动加载流畅
- 子文件夹标签可正常横滑访问（文件夹数量多时）

### FR-3 全屏查看器（P0）

**描述**：全屏沉浸式图片查看器，支持缩放、平移、滑动导航、缩略图跳转。

**需求细节**：
- **缩放**：双指捏合缩放 1x–4x，超过 1x 时可平移（拖动）
- **滑动**：缩放 1x 时左右滑动切换上一张/下一张（阈值 >50px）
- **导航**：左右半透明圆形箭头按钮（首/末张对应隐藏）；点击画面切换工具栏显隐
- **缩略图条**：底部横排当前图集缩略图，当前项白色描边高亮，点击跳转
- **信息**：底部显示文件名 + 尺寸（宽 × 高）
- **操作栏**：顶部返回、收藏、分享、更多（决策 #4：分享 = 系统分享面板 ACTION_SEND + FileProvider 分享原图；更多菜单内提供"保存到相册"写入系统媒体库）
- **沉浸**：进入查看器隐藏系统状态栏/导航栏，退出恢复
- **媒体播放**（决策 #5）：
  - 静态图：缩放/平移（1x–4x）
  - 动画 GIF/WebP：默认自动循环播放（Coil 解码动图），支持缩放平移
  - 视频：切换为播放器视图（Media3 ExoPlayer），支持播放/暂停、进度条拖动、音量、全屏；视频默认不自动播放，显示首帧+播放按钮，点击后播放
  - 在动图/视频间滑动切换时，离开视口的媒体自动暂停/停止播放以节省资源
  - 视频尺寸信息显示分辨率，动图显示帧尺寸

**验收标准**：
- 缩放平滑无跳变，1x→4x 无极变速
- 放大状态下拖动不触发翻页
- 缩略图条在 100+ 张图集中滚动定位正常
- GIF/WebP 动图自动循环播放，缩放平移正常
- 视频播放/暂停/拖动进度/音量正常；离开当前页自动停止
- 混合媒体（静态图+动图+视频）连续滑动切换不崩溃、不卡顿

### FR-4 文件夹标签与统计（P1）

**描述**：首页提供文件夹维度筛选与图库概览统计。

**需求细节**：
- 标签栏横滑（多文件夹时），含计数徽章
- 标签顺序：`All [总数]` → `收藏 [数]`（决策 #2，心形图标标签，聚合全部已收藏图片）→ 各文件夹标签（含子文件夹标签）
- 统计栏三项：`图片数` / `文件夹数` / `HD 数`
- 图片数随当前标签联动（All=总数，单文件夹=该夹数量，收藏=收藏总数）

### FR-5 质量标识 HD/SD（P1）

**描述**：缩略图左下角显示分辨率质量徽章。

**规则**：
- 宽 ≥1920 或 高 ≥1080 → HD（绿色徽章）
- 其余 → SD（橙色徽章）
- 徽章样式：圆角小标签，等宽字体，位于卡片左下角

### FR-6 收藏（P1）

**描述**：卡片与查看器均可收藏/取消收藏图片，支持跨文件夹聚合浏览收藏。

**需求细节**：
- 卡片右上角心形按钮（28px 圆形半透明底），已收藏为红色实心
- 查看器顶部心形同步状态
- 收藏状态跨会话保留
- **收藏聚合视图**（决策 #2）：首页"收藏"标签聚合展示全部已收藏图片（跨文件夹），复用瀑布流与查看器；取消收藏后从收藏视图即时消失

### FR-7 搜索（P2）

**描述**：按文件名模糊搜索当前图库。

**需求细节**：
- 搜索页独立 Tab，输入即时过滤
- 结果显示为瀑布流，可点击进入查看器
- 空查询显示引导文案；无结果显示"没有结果"

### FR-8 设置（P2）

**描述**：图库管理与显示偏好。

**需求细节**：
- 文件夹列表：每个文件夹显示名称 + 图片数 + 开关（启用/停用）；左滑/长按提供"移出"
- 添加文件夹入口
- 图片质量：HD 缩略图开关
- 网格列数：显示当前列数（2 列/3 列），点击切换并持久化（决策 #3）
- 清除缓存：释放缩略图缓存（显示缓存量）
- 关于：应用名 + 版本号

### FR-9 下拉刷新（P2）

**描述**：瀑布流顶部下拉刷新，重新扫描文件夹内容（新增/删除图片同步）。

**需求细节**：
- 下拉出现旋转图标 + "Pull to refresh" 提示
- 下拉超过阈值触发刷新，刷新中显示 "Refreshing..."
- 刷新完成自动回到原位

### FR-10 视频与动图支持（P1）

**描述**：图库统一管理静态图、动画 GIF/WebP 与视频（决策 #5），扫描、浏览、查看全链路支持。

**需求细节**：
- **扫描范围**：文件扫描同时匹配 `image/*` 与 `video/*` MIME；扩展名识别：静态图（jpg/jpeg/png/webp/bmp/heic/avif）+ 动画（gif、动画 webp）+ 视频（mp4/mkv/webm/mov/avi）
- **类型判定**：GIF 与 WebP 通过解码帧数判定是否为动画（帧数 >1 即动画）；视频按 MIME 判定
- **瀑布流**：动画/视频卡片显示首帧预览 + 类型角标（见 FR-1）；列表滚动时不自动播放
- **查看器**：动图自动循环播放；视频使用播放器视图（见 FR-3）
- **搜索**：支持按类型过滤（全部/图片/动图/视频）
- **统计**：统计栏在 HD 数基础上可扩展显示媒体分布（静态图/动图/视频数量），v1.0 至少保证总数正确
- **缩略图条**：视频缩略图带播放角标，动图缩略图带 GIF 角标

**验收标准**：
- 含静态图/GIF/WebP 动画/MP4 的文件夹扫描后，四类文件均出现在瀑布流，角标正确
- 动图在查看器自动循环播放；视频播放器播放/暂停/拖动/音量可用
- 按类型过滤搜索结果正确
- 视频文件损坏或无法解码时跳过不崩溃

### FR-11 排序能力（P1）

**描述**：首页图片浏览支持按时间 / 文件大小 / 图片质量排序，预览卡片上展示排序依据的值。

**需求细节**：
- **排序模式**（标题栏排序按钮，下拉菜单选择，选择持久化）：
  - 默认（扫描顺序）
  - 最新优先（按修改时间倒序）
  - 最旧优先（按修改时间正序）
  - 文件最大（按文件大小倒序）
  - 文件最小（按文件大小正序）
  - 画质优先（HD > SD > 视频）
- **排序依据值展示**：卡片右下角以深色半透明圆角小标签显示当前排序依据的值：
  - 时间模式：格式化日期（当年显示 `MM-dd`，跨年显示 `yyyy-MM-dd`）
  - 大小模式：人类可读大小（`B / KB / MB / GB`，如 `2.3 MB`）
  - 画质模式：复用左下角 HD/SD 徽章（不额外显示）
- **扫描元数据**：扫描时读取 SAF `COLUMN_SIZE` 与 `COLUMN_LAST_MODIFIED`（零 IO，随目录查询一并获取）
- **范围**：排序对"全部 / 收藏 / 文件夹 / 子文件夹"所有视图生效；查看器索引顺序跟随排序结果

**交互**：
- 标题栏排序按钮图标（Sort），激活非默认模式时图标高亮为紫色
- 下拉菜单样式与文件夹选择器一致（深色卡片、无分隔线、选中项紫色勾选）

**验收标准**：
- 六种排序模式均正确排序，切换即时生效
- 时间/大小值在卡片上正确显示，格式符合规范
- 排序选择重启后保持
- 排序与筛选（文件夹/子文件夹/收藏）组合工作正常

## 6. 非功能需求

### NFR-1 性能

| 指标 | 要求 |
|---|---|
| 冷启动 | ≤ 2s（1000 张图场景） |
| 瀑布流滚动帧率 | ≥ 55fps（500 张缩略图在屏） |
| 缩略图加载 | 首屏 20 张 ≤ 1.5s |
| 全屏图加载 | ≤ 1s（10MB 以内 JPEG） |
| 内存占用 | 常驻 ≤ 150MB（1000 张图库） |

### NFR-2 权限与隐私

- 采用 **SAF（Storage Access Framework）** 目录选择，无需申请存储读写权限
- 目录授权经 `takePersistableUriPermission` 持久化，用户可随时在系统设置撤销
- 不上传任何图片数据；收藏/文件夹列表仅存本地

### NFR-3 兼容性

- minSdk 26（Android 8.0），targetSdk 最新稳定版
- 适配全面屏手势导航、刘海屏 inset
- 支持横竖屏（竖屏优先）

### NFR-4 稳定性

- 扫描超大文件夹（1 万张）不崩溃，异步分页处理
- 损坏图片文件跳过不阻塞
- 应用进入后台/恢复不丢失浏览位置

## 7. 视觉规范（依据设计稿浏览器实测分析）

> 本节依据 `flowgallery-android.html` 在 Chromium 中的实际渲染逐界面分析提取。
> **本项目所有后续变更一律以本设计稿的样式风格为准。**

### 7.0 设计语言与风格原则（关键）

从设计稿提炼的核心 UI/UX 风格，任何新功能/组件必须遵循：

1. **深色沉浸基调**：全局深色背景（`#0A0A0C`），内容层用深灰卡片（`#141418` 系）浮起，层级靠"明度差"而非"边框线"区分 —— **优先使用留白和色阶分层，避免使用分隔线/描边**
2. **紫色单一强调**：`#7C5CFF` 是唯一强调色，只用于：激活/选中态、主操作（FAB、Add 按钮）、图标点缀。其他元素保持灰阶
3. **圆角体系**（统一语言）：
   - 卡片/条目：12px
   - 图标容器：8px
   - 标签胶囊：20px
   - 模态框/弹窗：顶部 24px（底部弹出式）
   - 徽章小标：4px
4. **卡片式条目**：列表条目 = 圆角卡片 + 左侧 40–48px 圆角图标容器（内嵌图标）+ 名称/描述两行文本 + 右侧操作元素；间距 8–12px
5. **弹窗/模态框统一为底部弹出卡片**：拖动把手（40×4px 圆角 2px）+ 大圆角 + 背景遮罩淡入 + 内容上滑 0.3s；**不使用系统默认 AlertDialog 白底样式**
6. **图标风格**：Material 线性图标（24px 基准），灰阶为主、紫色点缀；**不使用 emoji 或 Unicode 字符（如 ↳、›）充当图标**，层级用缩进/图标透明度表达
7. **文字层级**：主文字 `#F0F0F5` 15px SemiBold（条目名）→ 次级 `#A0A0B0` 12px（描述/路径）→ 弱化 `#606070` 9–11px（标签/计数）；等宽字体用于技术信息（尺寸、MD5）
8. **留白偏好**：页面水平内边距 16px，卡片内边距 12–16px，组件间距 8–12px；**宁可留白不要线条**
9. **动效克制**：0.2–0.3s 淡入/上滑/颜色渐变，按压 scale(0.98)，无夸张动画
10. **交互一致性**：同一类行为（点击画面、弹窗、选择器）在所有页面保持一致，不做页面特例

### 7.2 页面级规范（实测）

**首页 Home（当前实现）**
- 三段式：顶部信息区（标题+筛选+统计）/ 中部瀑布流 / 底部导航
- 标题栏：左"FlowGallery"标题，右侧 40×40 圆形图标按钮（搜索、**排序**、网格密度切换），背景 `#0A0A0C`
- **排序（FR-11）**：标题栏排序按钮弹出深色卡片菜单（圆角 16px，无分隔线，选中项紫色勾选）；六种模式（默认/最新/最旧/最大/最小/画质），激活非默认时按钮高亮紫色；卡片右下角深色半透明标签显示排序值（时间 `MM-dd` 或 `yyyy-MM-dd` / 大小 `2.3 MB`）
- **文件夹选择器（下拉，替代标签栏）**：单行卡片（圆角 14px，内边距 16×14），左侧图标 + 当前路径文本（`文件夹 / 子文件夹`）+ 计数 + 下拉箭头；下拉菜单为深色圆角 20px 卡片（无阴影无描边，靠色阶分层），菜单项 = 图标 + 名称 + 数量，子文件夹**缩进 + 图标淡化**区分，无分隔线、无 ↳ 字符
- 统计栏：深灰圆角 12px 条，三项 `[图标 16px 紫] 数字(14px 粗) + 标签(9px 大写)`：IMAGES / FOLDERS / HD
- 瀑布流：双列（可切 3 列）间距 10px，卡片圆角 12px，按宽高比自适应（后台解析尺寸渐进校正）
- 卡片元素：左下角 HD(绿)/SD(橙) 圆角徽章（等宽 9px，视频不显示质量徽章），左上角媒体类型角标（GIF/WEBP/▶），右上角 28px 圆形半透明底心形
- FAB：56×56 圆角 16px 紫色，白色 + 号，距右下 20px

**文件夹模态框 Folder Modal**
- 底部弹出（slide-up 0.3s + 背景淡入 0.2s），背景模糊遮罩 `rgba(0,0,0,0.7)`
- 顶部圆角 24px，含 40×4px 拖动把手（圆角 2px，`#2A2A35`）
- 标题 "Select Folders"（20px 粗体）
- 文件夹条目：48×48 圆角 8px 图标容器（紫色文件夹图标）+ 名称(15px 粗) + 路径(12px 灰) + 数量；右侧 24px 圆形勾选（选中紫色底白勾）
- 选中条目：紫色边框 2px + 紫色 15% 背景；未选中深灰背景
- "Add New Folder"：全宽，紫色 15% 背景 + 2px 紫色虚线边框，居中 + 图标 + 文字

**全屏查看器 Viewer（当前实现，图片/视频交互一致）**
- 纯黑背景全屏，顶部操作栏（返回/收藏/分享/更多 44px 圆形 `rgba(0,0,0,0.5)` 底），主图 contain 居中
- **点击画面 = 切换工具栏显隐**（图片与视频行为一致）
- 左右导航箭头：56px 圆形 `rgba(0,0,0,0.5)`，距边 12px，首/末张隐藏
- 图片缩放：1x–4x 捏合 + 平移；底部信息（文件名 14px + 尺寸 12px 等宽）+ 缩略图条 48×48 圆角 6px（当前项白色半透明高亮，**自动滚动居中当前项**）
- **视频自定义播放器**：Media3 画面 + 自制控制条（播放/暂停 + 进度条 Slider + 时间 mm:ss，半透明黑底，随工具栏显隐）；暂停时居中大播放按钮 + 首帧封面（Coil VideoFrameDecoder）
- **重复文件提示**（内容去重后）：底部信息区显示"该文件有 N 个副本"提示条（半透明白底圆角 8px），点击弹出**深色卡片弹窗**（拖动把手 + 24px 圆角 + 关闭按钮仿 Add 按钮样式），每条显示文件名/文件夹路径/MD5（等宽字体），当前文件紫色高亮

**搜索页 Search**

## 9. 数据模型（草案）

```
Folder
├── id: Long
├── name: String          # 文件夹名（根目录显示名）
├── uri: String           # SAF 树 URI
├── imageCount: Int       # 缓存统计（递归总数：根+全部子层级）
├── isSelected: Boolean   # 是否启用
└── subFolders: List<SubFolder>   # 一级子文件夹（递归浏览标签）
    └── SubFolder
        ├── id: Long
        ├── name: String          # 子文件夹名
        ├── uri: String           # 子文件夹文档 URI
        └── imageCount: Int       # 该子文件夹递归总数

ImageItem
├── id: Long
├── folderId: Long        # 所属根文件夹
├── folderName: String
├── subFolderId: Long?    # 所属一级子文件夹（null=根目录直接图片）
├── subFolderName: String?
├── name: String          # 文件名
├── uri: String           # 文档 URI
├── type: MediaType       # STATIC_IMAGE / ANIMATED_GIF / ANIMATED_WEBP / VIDEO
├── width: Int            # 真实宽度（视频为分辨率宽）
├── height: Int           # 真实高度（视频为分辨率高）
├── durationMs: Long?     # 视频时长（视频类型）
├── isFavorite: Boolean
└── isHd: Boolean(派生)   # w≥1920 || h≥1080
```
